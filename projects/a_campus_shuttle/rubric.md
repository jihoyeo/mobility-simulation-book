# 기말 개인 프로젝트 채점표 — 무당이 시뮬레이션 및 개선 분석

제출 전에 스스로 체크합니다. 채점도 이 표로 합니다. 상세 설명은 교재 「기말 프로젝트」 장에 있습니다.

## 데이터 준비 (20점)

- [ ] 정류장 좌표가 실제 정차 지점이고 노선별 순서가 있다 (3)
- [ ] GTFS 다섯 표가 validate_feed를 통과했다 (5)
- [ ] 패턴 수가 운행 수보다 작다 — 정류장 순서로 묶였다 (3)
- [ ] 조사표에 observed와 estimated 구분이 있고 비율을 적었다 (4)
- [ ] **데이터에서 이상한 점을 하나 이상 찾아 적었다** (5)

## 경로 탐색 정확도 (20점)

- [ ] O-D 100건을 고른 기준이 있다 (3)
- [ ] 자기 RAPTOR와 참조 구현을 100건 대조한 표가 있다 (7)
- [ ] 도착시각 60초 이내·환승 일치 기준을 벗어난 건수를 적었다 (4)
- [ ] 벗어난 건 하나의 원인을 경로 복원으로 설명했다 (6)

## 시나리오 설계 (20점)

- [ ] 시나리오 카드의 불편함과 시나리오가 이어진다 (4)
- [ ] GTFS 또는 시뮬레이션 입력을 실제로 고쳤고 고친 파일을 냈다 (6)
- [ ] 사전·사후를 **같은 O-D·같은 수요**로 비교했다 (6)
- [ ] 실현 가능한 안이다 (4)

## 지표 해석 (25점)

- [ ] 서비스율과 대기시간을 같이 냈다 (5)
- [ ] 평균과 함께 중앙값·90분위를 냈다 (4)
- [ ] 분포 그림과 공간 그림이 있다 (4)
- [ ] **개선의 대가를 적었다** (7)
- [ ] 어떤 조건에서 결론이 바뀌는지 적었다 (5)

## 보고서 완성도 및 재현성 (15점)

- [ ] 1절에 한 문장 결론이 있다 (3)
- [ ] 12.9절 여섯 항목(결론, 근거 표, 분포 그림, 비교 그림, 공간 그림, 한계)이 다 있다 (5)
- [ ] 코드를 받아 위에서부터 다시 돌릴 수 있다 (5)
- [ ] 절대 경로나 손으로 고친 중간 파일이 없다 (2)

| | |
|---|---|
| −5 | 서비스율 없이 평균 대기시간만 보고 |
| −5 | 개선 효과만 적고 대가를 적지 않음 |
| −5 | 한계 절이 없음 |
| −5 | 코드가 다시 돌아가지 않음 |
| −3 | 관측값과 추정값을 구분하지 않음 |
| −3 | 그림에 한글이 깨져 있음 |
