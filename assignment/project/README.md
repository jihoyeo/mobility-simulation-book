# 무당이 개인 프로젝트

프로젝트의 과업과 평가 기준은 [프로젝트 명세](../project.md), 주차별 진행 계획은 [일정](../../schedule.md)을 참고하세요.

현재는 조교의 시뮬레이션 실습에 앞서 각자 무당이 GTFS 데이터와 교내 도로망을 구축하는 단계입니다. 자료와 코드의 폴더 구성은 자유롭게 정하면 됩니다.

이후 각자 구축한 데이터를 활용해 시뮬레이션을 구현하고, 다양한 운영 시나리오를 비교하여 최적 운영전략을 제안합니다. 최종적으로 **분석 보고서와 시뮬레이션 실행 결과를 확인할 수 있는 대시보드**를 제출합니다.

## 1. 조교 실습용 시뮬레이션

조교 실습에서는 간단한 무당이 시뮬레이션을 직접 실행하면서 전체 개발 과정을 살펴봅니다.

- [슬라이드 교안](TA_SLIDES.md): GTFS 데이터 구성부터 승하차 인원 계산, 운영 시나리오 비교까지 설명하는 실습 자료
- [무당이 MVP](mudang-sim/README.md): Node.js와 Vite를 이용해 실행할 수 있는 시뮬레이션 예제

실습용 시뮬레이션은 반도체대학과 AI공학관을 연결하는 가상의 직통 노선을 대상으로 합니다. GTFS 데이터 생성, 도로망 최단경로 탐색, 차량 운행 및 승하차 처리, 운영 시나리오 비교를 순서대로 실습합니다.

실제 무당이 GTFS 구축, 도착예정시간(ETA) 추정, 수요 모형 개발 및 최종 대시보드 구현은 각자의 프로젝트에서 수행합니다.

참고로 단일 노선의 대기시간은 승객의 도착 시각과 탑승 시각을 이용해 계산할 수 있으므로 RAPTOR와 같은 대중교통 경로탐색 알고리즘을 반드시 사용할 필요는 없습니다.

## 2. 무당이 이용 기록 수집

시뮬레이션에 필요한 실제 이용 자료를 수집하기 위해 구글폼과 구글시트를 운영합니다. 무당이를 이용하면서 관찰한 승하차 인원, 대기인원, 대기시간 등을 가능한 범위에서 기록해 주세요.

### 2.1. 이용 기록 제출

**[무당이 이용 기록 입력 폼](https://docs.google.com/forms/d/e/1FAIpQLSde0U82eGr3m0ozSSRwib9F_Lf7Hht_Spqha13LJyNNHVrp2Q/viewform)**

휴대폰에서 날짜, 대략적인 시간과 관찰 내용을 자유롭게 입력하면 됩니다.

예를 들어 "반도체대학 정류장에서 앞에 20명 정도 있었고, 버스를 타기까지 15분 기다렸다"와 같이 기억나는 내용만 적어도 됩니다.

이름이나 이메일은 수집하지 않으며, 링크를 통해 누구나 응답할 수 있습니다. [입력 폼 바로가기](무당이_텍스트입력.webloc)를 이용해도 동일한 화면으로 연결됩니다.

### 2.2. 수집 자료 확인 및 정리

**[무당이 이용 기록 구글시트](https://docs.google.com/spreadsheets/d/1FXLIQbt2BC4Pm73Vbk7AZ4FzntJvRTgrij4VTdOXgqY/edit)**

수집한 자료는 구글시트에서 관리합니다.

구글폼으로 제출한 내용은 원문 그대로 저장되며, [응답 수집 노트북](../../labs/shuttle_text_responses.ipynb)을 실행하면 새로 제출된 응답을 구글시트의 '텍스트 원문' 탭으로 가져올 수 있습니다.

응답마다 고유 ID를 부여해 중복 수집을 방지합니다. 다만 자동 동기화나 데이터 정형화 기능은 설정되어 있지 않으므로, 새로운 응답을 가져오려면 노트북을 직접 실행해야 합니다.

수집한 내용은 원문을 확인한 뒤 '수요 기록' 탭의 항목에 맞게 정리합니다. 이때 원본 응답 ID와 정리한 데이터의 대응 관계를 남겨야 하며, 기록에 없는 수치나 승객의 출발지를 임의로 추정해서는 안 됩니다.

구글폼을 사용하지 않고 구글시트의 '수요 기록' 탭에 직접 입력해도 됩니다.

### 2.3. 수요 기록 작성 방법

'수요 기록' 탭에는 **한 정류장에서 차량 한 대를 관찰한 내용을 한 행으로 작성**합니다.

기록 항목은 이름, 날짜, 시간, 정류장, 승차 인원, 하차 인원, 대기인원, 본인의 대기시간과 이동시간 등입니다. 모든 항목을 채울 필요는 없으며, 직접 관찰하거나 확인한 내용만 작성하면 됩니다.

작성할 때는 다음 기준을 참고하세요.

- **시간:** 정확한 시각을 모르면 대략적인 시간을 기록합니다.
- **승차 및 하차 인원:** 직접 관찰했는데 해당 인원이 없었다면 0으로 기록하고, 확인하지 못했다면 빈칸으로 둡니다.
- **대기인원:** 본인이 정류장에 도착했을 때 기다리고 있던 인원으로, 본인도 포함합니다. 대략적인 숫자를 기록해도 됩니다.
- **대기시간:** 본인이 정류장에서 기다린 시간을 분 단위로 기록합니다.
- **이동시간:** 본인이 탑승한 구간의 이동시간을 분 단위로 기록합니다. 대기시간은 포함하지 않습니다.
- **목적지:** 목적 정류장을 알고 있는 경우에만 '목적 정류장'과 '해당 인원'을 입력합니다. 이때 출발지는 '정류장' 열에 기록된 정류장입니다.

본인의 이동만 기록했다면 목적지에 해당하는 인원은 1명입니다. 목적지가 여러 곳인 경우에는 행을 추가하되, 동일한 차량의 승차 인원, 하차 인원, 대기인원을 중복 입력하지 않도록 합니다.

목적지별 인원은 전체 승차 인원에 이미 포함될 수 있으므로 두 값을 합산하지 않습니다. 또한 여러 학생이 같은 차량을 관찰했다면 중복 여부를 확인한 후 집계해야 합니다.

**자료가 없는 시간대는 이용 수요가 0명이라는 뜻이 아닙니다.** 관찰하지 않은 항목은 임의로 채우지 않고 빈칸으로 남겨 주세요.
