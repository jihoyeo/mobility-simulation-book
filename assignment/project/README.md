# 무당이 개인 프로젝트

과업과 평가 기준은 [프로젝트 명세](../project.md), 진행 계획은 [일정](../../schedule.md)에 있습니다.

현재는 조교의 프로토타입 구현 실습에 사용할 GTFS와 교내 도로망을 각자 구축합니다.
자료와 코드의 폴더 구성은 학생이 정합니다.

이후 본인 데이터로 시뮬레이션을 구현하고, 시나리오 테스트를 거쳐 최적 운영전략을 도출합니다.
최종 제출물은 보고서와 시뮬레이션 구동 결과를 보여주는 대시보드입니다.

## 조교 실습용 시뮬레이션

[무당이 MVP](mudang-sim/README.md)는 Node.js와 Vite로 실행하는 독립 폴더입니다.
반도체대학–AI공학관 두 정류장만 잇는 가상의 직통 노선입니다.
GTFS 생성, 가상 도로망 최단경로, 차량 출발·승하차와 두 시나리오 비교를 순서대로 실습합니다.
실제 GTFS 구축, ETA 추정, 수요 모형과 최종 대시보드는 학생의 개발 과제로 남깁니다.
단일 노선의 대기시간은 승객 도착·탑승 시각으로 계산하므로 RAPTOR 사용은 필수가 아닙니다.

## 셔틀 이용 기록

[학생용 입력 폼](https://docs.google.com/forms/d/e/1FAIpQLSde0U82eGr3m0ozSSRwib9F_Lf7Hht_Spqha13LJyNNHVrp2Q/viewform)

학생은 휴대폰에서 날짜, 대략적인 시간, 관찰 내용을 입력합니다.
이름과 이메일은 수집하지 않습니다. 링크가 있는 누구나 응답할 수 있습니다.
‘앞에 20명이 있었고 15분 기다렸다’처럼 아는 내용만 자유롭게 적습니다.
[입력 폼 바로가기](무당이_텍스트입력.webloc)도 같은 화면을 엽니다.

응답 원문은 구글폼에 저장됩니다.
[응답 수집 노트북](../../labs/shuttle_text_responses.ipynb)을 실행하면 새 응답을 ‘텍스트 원문’ 탭에 복사합니다.
원문은 응답 ID로 구분하며, 이미 복사한 응답은 다시 추가하지 않습니다.
자동 동기화나 자동 정형화는 설정하지 않았습니다.
정형화할 때 원문을 확인해 아래 ‘수요 기록’ 열로 옮기며, 응답 ID와 결과 행의 대응을 남깁니다.
명시되지 않은 수치나 승객의 출발지는 추정하지 않습니다.

[구글시트](https://docs.google.com/spreadsheets/d/1FXLIQbt2BC4Pm73Vbk7AZ4FzntJvRTgrij4VTdOXgqY/edit)

정형화한 자료는 ‘수요 기록’ 탭에 모읍니다. 기존 방식으로 직접 기록해도 됩니다.
한 정류장에서 차량 한 대를 관찰한 내용을 한 행에 적습니다.
이름, 날짜, 대략적인 시간, 정류장, 탄 인원, 내린 인원, 대기인원, 본인이 기다린 시간을 기록합니다.
아는 항목만 채웁니다. 본인의 대기시간은 분으로 직접 적습니다.
본인이 탄 구간의 이동시간도 분으로 적을 수 있습니다. 대기시간은 포함하지 않습니다.
대기인원은 본인이 도착했을 때 본인을 포함한 수이며, 대략 적어도 됩니다.
탄 인원과 내린 인원은 관찰했는데 없으면 0, 모르면 빈칸입니다.

목적지를 아는 경우에만 ‘목적 정류장’과 ‘해당 인원’을 적습니다.
이때 ‘정류장’ 열이 출발지입니다. 본인의 이동만 기록하면 해당 인원은 1입니다.
목적지가 여러 곳이면 행을 추가하되 탄 인원·내린 인원·대기인원은 반복해서 적지 않습니다.
해당 인원은 탄 인원에 포함될 수 있으므로 두 값을 더하지 않습니다.
여러 작성자가 같은 차량을 기록한 경우 중복 여부를 확인한 뒤 집계합니다.
관찰하지 않은 시간대를 수요 0명으로 해석하지 않습니다.

2~4행은 여지호의 2026년 10월 28일 이용 상황을 가정한 작성예시입니다.
오전 11시 반도체대학 탑승, 대기 15분, 앞에 20명, AI공학관까지 이동 7분을 기록했습니다.
대기인원은 본인 포함 21명이며, 교육대학원 하차 4명과 AI공학관 하차 16명은 별도 행입니다.
AI공학관 시각 11:07은 탑승 시각과 이동시간으로 계산했습니다.
교육대학원 시각과 반도체대학 승차 인원은 확인되지 않아 비워 두었습니다.
목적지가 확인된 본인 1명만 출발지·목적지 쌍으로 기록했습니다.
노란색 작성예시 행은 실제 수요 집계에서 제외합니다.

공유 권한은 ‘링크가 있는 모든 사용자: 편집자’로 설정되어 있습니다.
학생에게 배포하는 링크는 위 입력 폼입니다. 구글시트에는 수집한 원문과 정형화한 자료를 모읍니다.
[구글시트 바로가기](셔틀_이용기록.webloc)를 열어도 같은 문서로 이동합니다.
[로컬 입력 양식](셔틀_이용기록.xlsx)은 별도 사본이며 온라인 기록과 자동으로 동기화되지 않습니다.
