# 8장 데이터 형태와 O-D 추정 예제

이 폴더의 일곱 CSV는 자료의 형태와 계산 원리를 설명하기 위한 가상 자료입니다.
실제 이용자의 기록이나 관측 통행량이 아닙니다.
[본문 8.1절과 8.3절](../../../ko/ch08_demand.md)에서 개념을 설명하고,
[실습 노트북 1절과 3절](../../../labs/ch08_demand.ipynb)에서 표와 그림을 확인합니다.

## 파일별 관측 단위

| 파일 | 한 행의 뜻 | 연결하거나 집계하는 기준 | 실습에서 확인할 것 |
| --- | --- | --- | --- |
| `smartcard.csv` | 환승 구간을 가로로 모은 통행사슬 | `트랜잭션ID`와 컬럼 끝의 구간 번호 | 3개 사슬을 4개 승차 구간으로 펼친 표와 시간선 |
| `telecom_od.csv` | 출발 격자·도착 격자·시간대별 집계량 | `O_ID`, `D_ID`, `O_TIME_CD` | 행 수와 통행량의 차이, O-D 행렬 |
| `taxi.csv` | 한 번의 승차·하차 | 같은 행의 양 끝 좌표와 시각 | 개별 O-D 화살표와 차내시간 |
| `gps_points.csv` | 한 시점의 위치 점 | `traj_uid`와 관측 시각 `t_ms` | 궤적과 양 끝 O-D의 차이 |
| `path_steps.csv` | 경로 위의 노드 하나 | `path_id`와 `sequence` | 경로의 노드 순서와 O-D 직선 연결의 차이 |
| `trip_ends.csv` | 한 구역의 출발량 또는 도착량 | `role`, `zone_id` | O-D 연결 없이 양 끝 총량만 주어진 경우 |
| `travel_times.csv` | 한 구역 쌍의 이동시간 | `origin`, `destination` | 중력모형의 이동 저항 입력 |

## 값과 단위

스마트카드 시각은 `YYYYMMDDHHMMSS` 문자열입니다.
빈 두 번째 구간은 환승하지 않은 경우입니다. 이용객 수는 모두 1입니다.
`DEMO_A`와 정류장 S1~S4는 가상 식별자이며, 정류장 좌표표는 포함하지 않습니다.

통신사 예제의 `MOVE_CNT`는 전수화 통행량을 표현한 값입니다.
네 행의 합은 40.0이며 08시대와 09시대는 각각 20.0입니다.
격자 ID는 가상이고, 이 예제에서 없는 구역 쌍은 0으로 둡니다.

택시 예제는 `p_x`, `d_x`를 경도, `p_y`, `d_y`를 위도로 정의합니다.
좌표계는 WGS84이고 시각은 한국 현지 시각입니다. 중간 경로는 포함하지 않습니다.

GPS의 `t_ms`는 유닉스 기준시각부터 지난 밀리초입니다.
한국 시각 2024-04-01 08:00, 08:02, 08:05, 08:10의 네 점이며 좌표계는 WGS84입니다.
예제에서는 중간에 끊기지 않은 통행 한 건으로 묶습니다.

가상 경로의 `x_km`, `y_km`는 km 단위 평면 좌표입니다.
실제 도로의 위치가 아니며, 통과 시각은 주어지지 않습니다.

중력모형 예제는 같은 분석 시간대의 출발량 O1=60, O2=40과 도착량 D1=50, D2=50을 사용합니다.
이동시간은 O1→D1과 O2→D2가 10분, 나머지 두 쌍이 20분입니다.
모든 구역 쌍은 연결되어 있고 이동시간은 양수입니다.
출발량과 도착량의 합이 다르거나 연결할 수 없는 구역 쌍이 있는 경우는 이 예제에서 다루지 않습니다.

## 계산 결과 확인

실습 노트북 1절은 자료 형태의 원래 표와 그림을, 3.3절은 중력모형의 입력·계산·결과를 표시합니다.
중력모형은 먼저 목적지 가중치 50·50과 저항함수 `1 / 이동시간²`로 출발량을 배분합니다.
처음 O-D는 `[[48, 12], [8, 32]]`이고 도착량은 56·44입니다.
행·열 합을 번갈아 조정하면 `[[44.09, 15.91], [5.91, 34.09]]`에 가까워집니다.
검사는 반올림 전 값으로 하며, 행 합 60·40과 열 합 50·50을 확인합니다.

구역 쌍을 확률로 뽑아 만든 요청 목록은 총 100건입니다.
무작위 표집 후의 각 O-D 건수와 행·열 합은 추정량에서 달라질 수 있습니다.

## 기존 하남 파일과의 구분

`data/hanam/od_2024.parquet`는 위 합성 예제와 별개인 교재 파일입니다.
날짜·요일·발췌 이력이 없어 집계 기간을 확인할 수 없습니다.
본문과 실습에서는 파일 내부의 시간대·목적지 비중을 사용하며, 합계를 하루 통행량으로 해석하지 않습니다.
`MOVE_DIST`, `MOVE_TIME`은 단위가 확인되지 않아 계산에서 제외합니다.

본문 그림 8.2~8.4는 `tools/build_ch08_figures.py`로 재현합니다.
그림 8.5와 수요 생성 실험실은 `tools/build_ch08_demand.py`로 만듭니다.
노트북 5절의 기준 요청 1,000건은 `data/hanam/demand.csv`에 있는 별도 교재 예제입니다.
