3학년 학부 수업용 교재로서 네 기준으로 검수했습니다. 강의는 슬라이드 없이 교재 웹과 노트북을 화면에 띄우고 진행하므로, 본문이 그대로 강의 대본입니다.

## 전체 판정

- **기준 2는 이미 충족.** React 0줄. JS 는 `labs/ch12_viewer/src/main.js` 빈칸 다섯 자리뿐이고 배선은 `viewer.js` 가 합니다. 남은 위험은 JS 문법 안내가 책에 없던 것과 실행 명령 블록 오류였고, 둘 다 고쳤습니다.
- **기준 4는 거의 충족.** `docs/STYLE.md` 와 `tools/kolint.py` 가 금지어를 걷어낸 상태였습니다(error 0). 남은 것은 린터가 못 잡는 세 가지였습니다. 문단 끝 경구형 단정, 근거 없는 수치·비교급, 조언 문장의 `~하세요`.
- **기준 1·3이 실제 문제.** 세 계통이 반복됐습니다.
  - 말없이 바뀌는 API: `sim.record`↔`sim.result`, 2-튜플↔3-튜플 이웃, 손으로 짠 `dijkstra`(튜플)↔라이브러리 `dijkstra`(`Path`), `ValueError`↔`NoPath`, `raptor_core`(튜플)↔`raptor`(객체)
  - 출력에 없는 숫자가 본문에: 4.2km, 7.4ms, 5분 30초 vs 34초, 1,000→990
  - 절의 마지막 코드 셀에 해석 없음. 그 자리가 대개 절의 결론(탐욕 vs 최적, ETA vs 라우팅)
- **난이도 점프는 채점받는 장에 몰려 있었습니다.** 3장(아이디어→12,566노드 구현 직행), 6장(장난감 시간표가 알고리즘 뒤에), 11장(본문이 보여 주는 것과 채점 빈칸이 어긋남). 세 장 모두 작은 예제를 구현 절 앞으로 옮겼습니다.
- **본문 주장이 데이터와 반대인 곳이 넷 있었습니다.** 4.1절 통계(거르지 않은 표로 계산해 15km/h·62.6% 가 나오는데 본문은 30km/h·21.7%), 4.3절 "큰길이 막히면 골목"(첨두 경로가 오히려 1차 간선을 더 탐), 6.7절 "새벽에는 도보만 남는다"(첫차를 기다려 4,195개 도달), 10.1절 "승객 1도 차량 0"(실제 겹침은 승객 1·2 → 차량 1). 전부 셀을 실행해 확인하고 고쳤습니다.
